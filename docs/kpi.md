# KPI (Key Performance Indicators)

## 1. 사용자 성장 지표

### 1.1 사용자 획득
- **신규 가입자 수 (DAU/MAU)**
  - 목표: 첫 달 1,000명, 3개월 5,000명, 6개월 10,000명
  - 측정: 일일/월간 활성 사용자 수

- **가입 전환율**
  - 목표: 방문자 대비 가입 전환율 10% 이상
  - 측정: 방문자 수 대비 가입자 수 비율

- **공동 가계부 생성률**
  - 목표: 개인 가계부 사용자 중 공동 가계부 생성률 30% 이상
  - 측정: 개인 가계부 사용자 중 공동 가계부 생성 비율

### 1.2 사용자 활성도
- **일일 활성 사용자 (DAU)**
  - 목표: 월간 활성 사용자의 30% 이상이 일일 활성
  - 측정: 하루에 최소 1회 이상 앱 사용한 사용자 수

- **주간 활성 사용자 (WAU)**
  - 목표: 월간 활성 사용자의 60% 이상이 주간 활성
  - 측정: 일주일에 최소 1회 이상 앱 사용한 사용자 수

- **월간 활성 사용자 (MAU)**
  - 목표: 6개월 내 10,000명 이상
  - 측정: 한 달에 최소 1회 이상 앱 사용한 사용자 수

## 2. 참여도 지표

### 2.1 지출 기록 활동
- **지출 기록 빈도**
  - 목표: 활성 사용자당 월평균 20건 이상 지출 기록
  - 측정: 사용자당 월간 지출 기록 건수

- **지속적인 사용률**
  - 목표: 가입 후 7일 이내 재방문률 50% 이상
  - 목표: 가입 후 30일 이내 재방문률 30% 이상
  - 측정: 가입 후 N일 이내 재방문한 사용자 비율

- **카테고리 활용도**
  - 목표: 사용자당 평균 5개 이상 카테고리 사용
  - 측정: 사용자당 사용한 카테고리 수

### 2.2 예산 관리 활동
- **예산 설정률**
  - 목표: 활성 사용자의 70% 이상이 예산 설정
  - 측정: 예산을 설정한 사용자 비율

- **예산 설정 카테고리 수**
  - 목표: 예산 설정 사용자당 평균 3개 이상 카테고리 예산 설정
  - 측정: 사용자당 예산 설정한 카테고리 수

- **예산 업데이트 빈도**
  - 목표: 예산 설정 사용자의 30% 이상이 월 1회 이상 예산 수정
  - 측정: 예산 수정 빈도

### 2.3 분석 기능 활용
- **대시보드 방문률**
  - 목표: 활성 사용자의 60% 이상이 주 1회 이상 대시보드 방문
  - 측정: 대시보드 방문 사용자 비율

- **통합 뷰 사용률**
  - 목표: 공동 가계부 사용자의 50% 이상이 통합 뷰 사용
  - 측정: 통합 뷰 사용 사용자 비율

## 3. 제품 품질 지표

### 3.1 기능 완성도
- **자동 감지 정확도**
  - 목표: 지출 타입 자동 감지 정확도 80% 이상
  - 측정: 자동 감지된 타입과 사용자 확인 타입 일치율

- **예산 제안 수용률**
  - 목표: 예산 자동 제안 수용률 40% 이상
  - 측정: 제안된 예산을 수용한 사용자 비율

- **예산 초과 알림 효과**
  - 목표: 예산 초과 알림 후 예산 조정률 30% 이상
  - 측정: 알림 받은 사용자 중 예산 조정한 비율

### 3.2 사용자 만족도
- **앱 평점**
  - 목표: 앱스토어 평점 4.5점 이상 (5점 만점)
  - 측정: 사용자 리뷰 평균 평점

- **NPS (Net Promoter Score)**
  - 목표: NPS 50 이상
  - 측정: 추천 의향 점수 (0-10점)

- **고객 만족도 (CSAT)**
  - 목표: 고객 만족도 80% 이상
  - 측정: 만족도 설문 조사 결과

## 4. 비즈니스 지표

### 4.1 사용자 유지
- **1일 유지율**
  - 목표: 가입 후 1일 유지율 60% 이상
  - 측정: 가입 후 1일 이내 재방문한 사용자 비율

- **7일 유지율**
  - 목표: 가입 후 7일 유지율 40% 이상
  - 측정: 가입 후 7일 이내 재방문한 사용자 비율

- **30일 유지율**
  - 목표: 가입 후 30일 유지율 25% 이상
  - 측정: 가입 후 30일 이내 재방문한 사용자 비율

- **이탈률**
  - 목표: 월간 이탈률 10% 이하
  - 측정: 전월 활성 사용자 중 당월 비활성 사용자 비율

### 4.2 수익성 (향후)
- **프리미엄 전환율**
  - 목표: 무료 사용자 중 프리미엄 전환율 5% 이상
  - 측정: 프리미엄 구독한 사용자 비율

- **월간 반복 수익 (MRR)**
  - 목표: 6개월 내 월간 반복 수익 100만원 이상
  - 측정: 프리미엄 구독료 합계

- **고객 생애 가치 (LTV)**
  - 목표: 고객 생애 가치 50,000원 이상
  - 측정: 사용자당 평균 수익

## 5. 기술적 지표

### 5.1 성능
- **앱 로딩 시간**
  - 목표: 초기 로딩 시간 2초 이하
  - 측정: 앱 실행부터 메인 화면 표시까지 시간

- **API 응답 시간**
  - 목표: API 평균 응답 시간 500ms 이하
  - 측정: API 요청부터 응답까지 평균 시간

- **오류율**
  - 목표: 오류율 0.1% 이하
  - 측정: 전체 요청 중 오류 발생 비율

### 5.2 안정성
- **크래시율**
  - 목표: 크래시율 0.01% 이하
  - 측정: 세션 중 크래시 발생 비율

- **가동 시간**
  - 목표: 서비스 가동 시간 99.9% 이상
  - 측정: 전체 시간 대비 서비스 정상 동작 시간 비율

## 6. 측정 방법

### 6.1 분석 도구
- **사용자 행동 분석**: Google Analytics, Mixpanel 등
- **앱 성능 모니터링**: Sentry, Firebase Performance 등
- **사용자 피드백**: 인앱 설문, 리뷰 분석 등

### 6.2 측정 주기
- **일일**: DAU, 지출 기록 건수 등
- **주간**: WAU, 주간 유지율 등
- **월간**: MAU, 월간 유지율, 예산 설정률 등
- **분기**: NPS, CSAT, LTV 등

### 6.3 리포트
- **일일 리포트**: 주요 지표 일일 현황
- **주간 리포트**: 주간 트렌드 및 이슈 분석
- **월간 리포트**: 월간 성과 및 개선 사항
- **분기 리포트**: 분기별 목표 달성도 및 전략 수정
