# Information Architecture (IA)

## 1. 사이트맵 (Sitemap)

```
The Moa
│
├─ 대시보드 (Dashboard)
│  ├─ 개인 가계부 대시보드
│  ├─ 공동 가계부 대시보드
│  └─ 통합 대시보드
│
├─ 가계부 (Book)
│  ├─ 개인 가계부
│  │  ├─ 지출 내역
│  │  ├─ 수입 내역
│  │  └─ 캘린더 뷰
│  │
│  └─ 공동 가계부
│     ├─ 지출 내역
│     ├─ 수입 내역
│     └─ 캘린더 뷰
│
├─ 예산 (Budget)
│  ├─ 개인 예산
│  │  ├─ 예산 설정
│  │  ├─ 예산 수정
│  │  └─ 예산 이력
│  │
│  └─ 공동 예산
│     ├─ 예산 설정
│     ├─ 예산 수정
│     └─ 예산 이력
│
├─ 카테고리 (Category)
│  ├─ 카테고리 목록
│  ├─ 카테고리 추가
│  ├─ 카테고리 수정
│  └─ 카테고리 설정
│
├─ 분석 (Analytics)
│  ├─ 지출 분석
│  ├─ 예산 대비 지출
│  ├─ 카테고리별 분석
│  └─ 시계열 분석
│
├─ 설정 (Settings)
│  ├─ 프로필 설정
│  ├─ 가계부 설정
│  ├─ 알림 설정
│  └─ 계정 설정
│
└─ 공동 가계부 관리 (Shared Book Management)
   ├─ 공동 가계부 생성
   ├─ 파트너 초대
   ├─ 권한 관리
   └─ 공동 가계부 삭제
```

## 2. 네비게이션 구조

### 2.1 메인 네비게이션

```
[사이드바 / 상단 네비게이션]

┌─────────────────────────────┐
│ The Moa                     │
├─────────────────────────────┤
│ 📊 대시보드                 │
│   ├─ 개인 가계부            │
│   ├─ 공동 가계부            │
│   └─ 통합 보기              │
│                             │
│ 📖 가계부                   │
│   ├─ 개인 가계부            │
│   └─ 공동 가계부            │
│                             │
│ 💰 예산                     │
│   ├─ 개인 예산              │
│   └─ 공동 예산              │
│                             │
│ 📁 카테고리                 │
│                             │
│ 📈 분석                     │
│                             │
│ ⚙️ 설정                     │
└─────────────────────────────┘
```

### 2.2 컨텍스트 네비게이션

**가계부 페이지 내:**

- 월/년 선택기
- 개인/공동/통합 필터
- 지출/수입 탭

**예산 페이지 내:**

- 월/년 선택기
- 개인/공동 필터
- 카테고리별 예산 목록

**분석 페이지 내:**

- 기간 선택기
- 개인/공동/통합 필터
- 분석 타입 선택 (지출/예산/카테고리)

## 3. 페이지 구조

### 3.1 대시보드 (Dashboard)

**경로:** `/dashboard`

**구조:**

```
┌─────────────────────────────────────┐
│ [가계부 선택: 개인/공동/통합]       │
├─────────────────────────────────────┤
│ [월/년 선택기]                      │
├─────────────────────────────────────┤
│ 총 수입: XXX만원                    │
│ 총 예산: XXX만원                    │
│ 총 지출: XXX만원                    │
│ 예산 대비: XX%                      │
├─────────────────────────────────────┤
│ [예산 대비 지출 차트]               │
├─────────────────────────────────────┤
│ [카테고리별 지출 현황]              │
├─────────────────────────────────────┤
│ [최근 지출 내역]                    │
└─────────────────────────────────────┘
```

**기능:**

- 가계부 선택 (개인/공동/통합)
- 월/년 선택
- 총 수입/예산/지출 요약
- 예산 대비 지출 시각화 : 동일 카테고리 지난 기간 예산 대비 지출과 함께 추이 시각화
- 카테고리별 지출 현황 : 선택한 기간(월/년) 내 카테고리별 지출 현황
- 최근 지출 내역

### 3.2 가계부 (Book)

**경로:** `/book` (개인), `/book/shared` (공동)

**구조:**

```
┌─────────────────────────────────────┐
│ [지출/수입 탭]                      │
├─────────────────────────────────────┤
│ [월/년 선택기]                      │
├─────────────────────────────────────┤
│ [캘린더 뷰 / 리스트 뷰]            │
├─────────────────────────────────────┤
│ [지출/수입 추가 버튼]               │
└─────────────────────────────────────┘
```

**기능:**

- 지출/수입 내역 조회
- 캘린더 뷰 / 리스트 뷰 전환
- 지출/수입 추가
- 지출/수입 수정/삭제
- 카테고리별 필터링

### 3.3 예산 (Budget)

**경로:** `/budget` (개인), `/budget/shared` (공동)

**구조:**

```
┌─────────────────────────────────────┐
│ [개인/공동 선택]                    │
├─────────────────────────────────────┤
│ [월/년 선택기]                      │
├─────────────────────────────────────┤
│ 총 예산: XXX만원                    │
│ 총 지출: XXX만원                    │
│ 예산 대비: XX%                      │
├─────────────────────────────────────┤
│ [카테고리별 예산 목록]              │
│   - 카테고리명                      │
│   - 예산 금액                       │
│   - 지출 금액                       │
│   - 사용률                          │
│   - [수정] 버튼                     │
├─────────────────────────────────────┤
│ [예산 추가 버튼]                    │
└─────────────────────────────────────┘
```

**기능:**

- 카테고리별 예산 조회
- 예산 추가/수정/삭제
- 예산 대비 지출 현황
- 예산 이력 조회
- 예산 초과 알림

- 예산 연결

## 4. 사용자 플로우

### 4.1 신규 사용자 온보딩

```
1. 회원가입
   ↓
2. 개인 가계부 생성 (자동)
   ↓
3. 온보딩 가이드
   - 서비스 소개
   - 첫 카테고리 추가
   - 첫 지출 기록
   ↓
4. 대시보드로 이동
   ↓
5. (선택) 예산 설정 가이드
```

### 4.2 지출 기록 플로우

```
1. 가계부 페이지 접근
   ↓
2. [지출 추가] 버튼 클릭
   ↓
3. 지출 입력 폼
   - 금액
   - 카테고리 선택
   - 날짜
   - 메모
   ↓
4. 저장
   ↓
5. 지출 내역에 추가됨
```

### 4.3 예산 설정 플로우

```
1. 예산 페이지 접근
   ↓
2. [예산 추가] 버튼 클릭
   ↓
3. 카테고리 선택
   ↓
4. 예산 입력
   - 금액
   - 기간 (월/년)
   - 시작일
   ↓
5. 저장
   ↓
6. 예산 목록에 추가됨
```

### 4.4 공동 가계부 생성 플로우

```
1. 설정 > 공동 가계부 관리
   ↓
2. [공동 가계부 만들기] 클릭
   ↓
3. 파트너 초대
   - 이메일 입력
   - 초대 메시지
   ↓
4. 파트너 승인 대기
   ↓
5. 파트너 승인 완료
   ↓
6. 공동 가계부 생성 완료
   ↓
7. (선택) 예산 설정 가이드
```

## 5. 정보 구조 원칙

### 5.1 계층 구조

- **1차**: 가계부 타입 (개인/공동)
- **2차**: 기능 영역 (대시보드/가계부/예산/카테고리/분석)
- **3차**: 세부 기능 (지출/수입, 예산 설정/수정 등)

### 5.2 네비게이션 원칙

- **명확성**: 각 메뉴의 목적이 명확해야 함
- **일관성**: 동일한 기능은 동일한 위치에 배치
- **접근성**: 주요 기능은 3클릭 이내 접근 가능

### 5.3 정보 표시 원칙

- **계층적 표시**: 중요 정보를 상단에 배치
- **시각적 구분**: 개인/공동 정보를 색상으로 구분
- **상태 표시**: 예산 초과, 알림 등 상태를 명확히 표시

## 6. 반응형 구조

### 6.1 모바일 (Mobile)

- **네비게이션**: 하단 탭 바 또는 햄버거 메뉴
- **레이아웃**: 단일 컬럼, 세로 스크롤
- **입력**: 큰 터치 영역, 간편한 입력 폼

### 6.2 태블릿 (Tablet)

- **네비게이션**: 사이드바 또는 상단 메뉴
- **레이아웃**: 2컬럼 가능, 가로 공간 활용
- **입력**: 모바일과 유사하되 더 넓은 화면 활용

### 6.3 데스크탑 (Desktop)

- **네비게이션**: 고정 사이드바
- **레이아웃**: 멀티 컬럼, 대시보드 중심
- **입력**: 모달 또는 사이드 패널 활용

## 7. 데이터 모델 관계

```
User (사용자)
  ├─ Book (가계부) [1:N]
  │   ├─ Category (카테고리) [1:N]
  │   ├─ Budget (예산) [1:N]
  │   ├─ Expense (지출) [1:N]
  │   └─ Income (수입) [1:N]
  │
  └─ SharedBook (공동 가계부) [N:M]
      └─ Book (가계부) [1:1]
```

## 8. 검색 및 필터링

### 8.1 검색 기능

- **지출/수입 검색**: 금액, 카테고리, 메모로 검색
- **예산 검색**: 카테고리명으로 검색
- **카테고리 검색**: 카테고리명으로 검색

### 8.2 필터링 기능

- **기간 필터**: 월/년/기간 선택
- **카테고리 필터**: 카테고리별 필터링
- **타입 필터**: 지출 타입별 필터링 (고정/변동/연간/일회)
- **가계부 필터**: 개인/공동/통합 필터
