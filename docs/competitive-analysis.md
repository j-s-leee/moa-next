# 경쟁분석 (Competitive Analysis)

## 1. 경쟁사 현황

### 1.1 국내 가계부 앱

#### 가계부톡 (MoneyTalk)
**강점:**
- 부부 공동 가계부 기능 제공
- 간편한 지출 입력
- 카드 연동 기능

**약점:**
- 예산 관리 기능이 제한적
- 개인/공동 가계부 분리가 명확하지 않음
- 예산 자동 제안 기능 없음

#### 머니부 (Moneyboo)
**강점:**
- 예산 관리 기능 강화
- 다양한 차트 및 분석 기능
- 카테고리 관리 기능

**약점:**
- 공동 가계부 기능 부재
- 예산 이력 관리 기능 없음
- 지출 타입 자동 감지 기능 없음

#### 하우스홀드 (Household)
**강점:**
- 가족 단위 가계부 관리
- 공동 지출 관리 기능

**약점:**
- 개인 가계부와의 통합 부족
- 예산 관리 기능 제한적
- 모바일 중심, 데스크탑 지원 부족

### 1.2 해외 가계부 앱

#### YNAB (You Need A Budget)
**강점:**
- 강력한 예산 관리 기능
- 예산 기반 소비 철학
- 데스크탑 + 모바일 지원

**약점:**
- 유료 서비스 (월 $14.99)
- 한국어 지원 부족
- 공동 가계부 기능이 제한적

#### Mint
**강점:**
- 자동 거래 연동
- 무료 서비스
- 다양한 분석 기능

**약점:**
- 예산 관리 기능이 단순함
- 공동 가계부 기능 부재
- 한국 서비스 부재

## 2. 차별화 포인트

### 2.1 개인 + 공동 가계부 통합 관리
**경쟁사 대비 우위:**
- 개인 가계부와 공동 가계부를 별도로 관리하되 통합 뷰 제공
- 개인 가계부에서 공동 가계부로 자연스러운 전환 지원
- 각 가계부의 독립적인 카테고리, 예산, 지출 내역 관리

**경쟁사 현황:**
- 대부분 개인 또는 공동 가계부 중 하나만 지원
- 통합 관리 기능 부재

### 2.2 지능형 지출 분류
**경쟁사 대비 우위:**
- 지출 타입 자동 감지 (고정지출/변동지출)
- 변동계수 기반 자동 분류 알고리즘
- 사용자 확인을 통한 점진적 개선

**경쟁사 현황:**
- 대부분 사용자가 직접 타입을 선택해야 함
- 자동 감지 기능 부재

### 2.3 예측 기반 예산 관리
**경쟁사 대비 우위:**
- 과거 데이터 기반 예산 자동 제안
- 예산 변경 이력 추적 및 시각화
- 연간 예산 중간 수정 시나리오 처리

**경쟁사 현황:**
- 예산 자동 제안 기능이 제한적
- 예산 이력 관리 기능 부재

### 2.4 유연한 예산 설정
**경쟁사 대비 우위:**
- 예산 설정은 선택사항이지만 강력히 권장
- 점진적 예산 관리 지원
- 예산 없이도 지출 기록 가능

**경쟁사 현황:**
- 대부분 예산 설정을 필수로 요구
- 초기 진입 장벽이 높음

### 2.5 크로스 플랫폼 최적화
**경쟁사 대비 우위:**
- 모바일: 쉬운 지출 입력에 최적화
- 데스크탑: 큰 화면으로 통합 분석 제공
- 동일 서비스에서 두 플랫폼 모두 지원

**경쟁사 현황:**
- 대부분 모바일 중심
- 데스크탑 지원이 제한적이거나 별도 서비스

## 3. 경쟁 우위 전략

### 3.1 기술적 우위
- **자동 감지 알고리즘**: 변동계수 기반 지출 타입 자동 감지
- **예산 제안 엔진**: 머신러닝 기반 예산 자동 제안 (향후)
- **실시간 동기화**: 개인/공동 가계부 실시간 동기화

### 3.2 사용자 경험 우위
- **점진적 온보딩**: 예산 없이도 시작 가능, 점진적으로 예산 설정 유도
- **명확한 정보 제공**: 통합 뷰에서 개인/공동 구분 명확히 표시
- **유연한 재조정**: 예산 초과 시 가이드 제공, 강제 변경 없음

### 3.3 기능적 우위
- **4가지 지출 타입**: 고정/변동/연간예산/일회성 지출 구분
- **예산 이력 관리**: 예산 변경 추이 시각화
- **수입 이체 추적**: 개인 수입에서 공동 수입으로 이체 관리

## 4. 시장 기회

### 4.1 시장 규모
- 한국 가계부 앱 시장: 연간 약 500억원 규모
- 타겟 사용자: 결혼한 부부 약 1,000만 가구
- 잠재 사용자: 개인 가계부 사용자 약 2,000만명

### 4.2 시장 트렌드
- **예산 기반 소비**: 계획적 소비에 대한 관심 증가
- **공동 관리**: 부부 공동 가계부 관리 수요 증가
- **데이터 기반 인사이트**: AI 기반 예산 제안에 대한 관심

### 4.3 진입 장벽
- **기존 사용자 전환**: 기존 가계부 앱 사용자의 전환 비용
- **데이터 마이그레이션**: 기존 데이터 이전 기능 필요
- **신뢰 구축**: 재무 정보 관리에 대한 신뢰 구축

## 5. 경쟁 전략

### 5.1 차별화 전략
- 개인 + 공동 가계부 통합 관리로 타겟 사용자 명확히 타겟팅
- 지능형 자동 감지로 사용자 편의성 극대화
- 예측 기반 예산 관리로 장기 사용 가치 제공

### 5.2 가격 전략
- **무료 플랜**: 기본 기능 무료 제공
- **프리미엄 플랜**: 고급 분석 기능, 무제한 예산 설정 등 (향후)

### 5.3 마케팅 전략
- **타겟 마케팅**: 결혼한 부부 타겟 온라인 마케팅
- **컨텐츠 마케팅**: 예산 관리 팁, 가계부 활용법 블로그
- **파트너십**: 결혼 정보 회사, 부동산 앱 등과의 협업
