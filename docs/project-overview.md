# The Moa 프로젝트 개요

## 1. 프로젝트 소개

### 1.1 프로젝트명

**The Moa** - 개인 및 부부 공동 가계부 관리 서비스

### 1.2 프로젝트 비전

개인 가계부와 부부 공동 가계부를 한 서비스에서 관리하며, 예산 기반의 계획적 소비와 중장기적인 저축을 지원하는 가계부 서비스

### 1.3 핵심 가치 제안

- **개인 + 공동 통합 관리**: 개인 가계부와 공동 가계부를 별도로 관리하되 통합 뷰 제공
- **예측 기반 예산 관리**: 과거 데이터 기반으로 다음 달/다음 해 예산 자동 제안
- **지능형 지출 분류**: 자동 감지로 고정지출/변동지출 구분
- **유연한 예산 설정**: 예산은 선택사항이지만 강력히 권장, 점진적 예산 관리 지원
- **크로스 플랫폼**: 모바일(쉬운 입력) + 데스크탑(큰 화면 분석)

## 2. 타겟 사용자

### 2.1 Primary Persona

**부부 가계부 사용자 (30-40대)**

- 결혼한 부부로 공동 생활비와 개인 용돈을 분리하여 관리하고 싶은 사용자
- 예산을 세우고 계획적으로 소비하고 싶은 사용자
- 중장기적인 저축 목표가 있는 사용자

### 2.2 Secondary Persona

**개인 가계부 사용자 (20-30대)**

- 혼자 살면서 가계부를 관리하는 사용자
- 나중에 공동 가계부로 확장할 가능성이 있는 사용자

## 3. 핵심 기능

### 3.1 가계부 관리

- **개인 가계부**: 개인 수입/지출 관리
- **공동 가계부**: 부부 공동 수입/지출 관리
- **통합 뷰**: 개인 + 공동 통합 대시보드

### 3.2 예산 관리

- **월별/연별 예산 설정**: 카테고리별 예산 설정
- **예산 이력 관리**: 예산 변경 이력 추적 및 시각화
- **예산 대비 지출 추적**: 실시간 예산 사용률 모니터링
- **예산 자동 제안**: 과거 데이터 기반 예산 제안

### 3.3 지출 분류

- **자동 타입 감지**: 고정지출/변동지출 자동 감지
- **4가지 지출 타입**:
  - 고정지출: 매월 동일 금액 (통신비, 월세 등)
  - 변동지출: 매월 발생하지만 금액 변동 (식비, 공과금 등)
  - 연간예산지출: 연간 총액 예산, 월별 저축 누적 (의류비, 여행비 등)
  - 일회성지출: 긴급/비상 지출 (병원비 등)

### 3.4 수입 관리

- **고정수입**: 매주/매월/매년 고정 수입
- **변동수입**: 불규칙한 수입
- **수입 이체 관리**: 개인 수입에서 공동 수입으로 이체 추적

### 3.5 분석 및 인사이트

- **시계열 분석**: 카테고리별 과거 지출 추이 분석
- **예산 변경 추이**: 예산 변경 이력 시각화
- **예산 대비 지출 분석**: 월별/연별 집계 및 시각화
- **예산 초과 알림**: 예산 초과 시 알림 및 경고

## 4. 기술 스택

- **Frontend**: Next.js, React, TypeScript
- **UI**: Tailwind CSS, shadcn/ui, Lucide Icons
- **State Management**: React Context / Zustand
- **Backend**: Supabase
- **Database**: Supabase (PostgreSQL)
- **ORM**: Drizzle ORM
- **Icons**: Lucide React
