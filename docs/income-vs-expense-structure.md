# 수입과 지출 테이블 구조 차이

## 1. 구조 차이 요약

### 지출 (Expenses)
- **단일 거래**: 특정 날짜의 지출 내역
- **카테고리 필수**: 모든 지출은 카테고리와 연결
- **예산 자동 연결**: 카테고리와 날짜를 기반으로 예산 자동 연결
- **사용자 추적**: 누가 입력했는지 기록 (공동 가계부에서 중요)

### 수입 (Incomes)
- **단일 거래 수입**: 특정 날짜의 일회성 수입 (프리랜서, 자영업자 등)
- **반복 수입**: 기간 기반의 반복 수입 (급여, 용돈 등)
- **기간 설정**: startDate ~ endDate (무기한 가능, 반복 수입만)
- **반복 주기**: monthly (월간) 또는 yearly (연간, 반복 수입만)
- **이체 지원**: 개인 가계부 → 공동 가계부 이체 기능

## 2. 왜 다른 구조인가?

### 2.1 지출의 특성
- **일회성 거래**: 매일 발생하는 개별 거래
- **예측 불가능**: 언제 얼마를 쓸지 모름
- **카테고리 중심**: 카테고리별로 예산 관리

**예시:**
```
2024-01-15: 식비 15,000원
2024-01-16: 교통비 3,000원
2024-01-17: 식비 12,000원
```

### 2.2 수입의 특성
- **단일 거래**: 프리랜서, 자영업자 등 불규칙한 수입
- **반복성**: 매월 또는 매년 반복되는 수입 (급여, 용돈 등)
- **예측 가능**: 급여는 매월 고정
- **기간 기반**: 특정 기간 동안 유효한 수입 (반복 수입만)

**예시:**
```
단일 거래:
프리랜서 프로젝트: 2024-01-15, 500만원
자영업 매출: 2024-01-20, 200만원

반복 수입:
급여: 300만원/월 (2024-01-01 ~ 무기한)
용돈: 10만원/월 (2024-01-01 ~ 2024-12-31)
```

## 3. 데이터 모델 비교

### 지출 (Expenses)
```typescript
interface Expense {
  id: string;
  bookId: string;
  categoryId: string;        // 필수: 카테고리 연결
  amount: number;           // 금액
  date: Date;               // 단일 날짜
  description?: string;     // 메모
  userId: string;           // 누가 입력했는지
  budgetId?: string;        // 자동 연결된 예산
}
```

### 수입 (Incomes)
```typescript
interface Income {
  id: string;
  bookId: string;
  categoryId?: string;      // 선택: 카테고리 (최근 추가됨)
  amount: number;           // 금액
  date: Date | null;        // 단일 거래 날짜 (단일 거래인 경우)
  period: "monthly" | "yearly" | null;  // 반복 주기 (반복 수입인 경우)
  source?: string;          // 수입 출처 (선택사항)
  incomeType: "actual" | "transfer";  // 실제 수입 vs 이체
  transferredFromBookId?: string;     // 이체 출처
  startDate: Date | null;   // 시작 날짜 (반복 수입인 경우)
  endDate?: Date | null;    // 종료 날짜 (null이면 무기한, 반복 수입인 경우)
}
```

## 4. 사용 시나리오

### 지출 시나리오
```
사용자: "오늘 커피 5,000원 샀어"
→ 단일 거래 기록
→ 카테고리: 음식/카페
→ 날짜: 오늘
→ 예산 자동 연결
```

### 수입 시나리오

**단일 거래 수입:**
```
사용자: "프리랜서 프로젝트로 500만원 받았어"
→ 단일 거래 수입 기록
→ 날짜: 2024-01-15
→ 카테고리: 프리랜서
→ 지출 탭에 지출과 함께 날짜별로 표시
```

**반복 수입:**
```
사용자: "매월 급여 300만원 받아"
→ 반복 수입 설정
→ 기간: 2024-01-01 ~ 무기한
→ 주기: 월간
→ 카테고리: 급여
→ 수입 탭에 별도로 표시
```

## 5. 통합 방향

현재 수입에도 카테고리를 추가하고, 단일 거래 수입을 지출과 통합하여 일관성을 맞추고 있습니다:
- ✅ 카테고리 선택 가능
- ✅ 카테고리별 수입 집계
- ✅ 단일 거래 수입과 지출 통합 표시
- ✅ 지출 탭에서 지출과 단일 거래 수입을 날짜별로 함께 표시
- ✅ 수입 탭에서는 반복 수입만 별도로 표시

구조적 차이:
- 지출: 단일 거래 (date)
- 수입: 
  - 단일 거래 수입 (date) - 지출 탭에 통합 표시
  - 반복 수입 (startDate, endDate, period) - 수입 탭에 별도 표시
